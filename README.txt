TIRBET24 — MAQUETTE MODIFIABLE
================================
Ceci est une maquette front-end indépendante, pas une copie des fichiers originaux du serveur.

OUVRIR :
1. Décompressez le ZIP.
2. Ouvrez index.html dans Chrome, Firefox ou Edge.
3. Modifiez les textes et sections dans index.html.
4. Modifiez les couleurs et l’apparence dans css/style.css.
5. Modifiez les cartes d’événements et jeux dans js/app.js.

LIMITES :
- Pas de base de données, comptes, soldes, paiements ou administration.
- Les fichiers originaux et la base de données ne peuvent être récupérés depuis le lien public seul.
- N’utilisez que les marques, images, jeux et contenus pour lesquels vous avez les droits.
- Pour connecter une vraie base de données, un système de comptes ou publier sur un serveur, il faut une autorisation d’administration et un backend sécurisé.
